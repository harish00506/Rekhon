# =============================================================================
# Frozen evaluation set for Stage-1 auto-categorisation (issue 4.2; SRS §8, §21.5).
#
# Why a text file and not JSON: this module is pure Kotlin with no serialisation
# dependency by design (ARC-002), so the set is parsed by the test that reads it
# — the same bargain `:domain:engines:sms`'s eval/sms.txt struck.
#
# Format: records separated by a line of `===`. Each record is
#     # merchant=<the descriptor, exactly as a bank or a user would write it>
#     # expect=<a category_defaults display name, or `none`>
# Any other line beginning with `#` is a comment, including this block.
#
# `expect=none` means Stage 1 MUST propose nothing. That half is scored at zero
# tolerance: a merchant the app declines to classify costs the user one tap on a
# chip row already on screen, while a merchant it classifies WRONGLY files money
# under a category they never chose, into a budget they will later read as fact.
#
# The labelled half is scored at ≥ 92 % (SRS §8). It is NOT 100 %, and the two
# misses are left in on purpose — see `# KNOWN MISS` below. A set curated until
# it scores perfectly measures the curation, not the engine.
# =============================================================================
