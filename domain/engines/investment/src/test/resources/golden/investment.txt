# Golden cases for :domain:engines:investment - the money-weighted return (XIRR) over dated cash
# flows (issue 6.3; §11, P-08).
#
# WHERE THESE NUMBERS COME FROM: an independent 60-significant-digit decimal implementation that
# solves NPV(r) = sum cf_i * (1+r)^(-days_i/365) = 0 directly, using exp/ln for the fractional
# powers. The engine does something different on purpose - it substitutes x = (1+r)^(1/365) and
# bisects a polynomial in integer powers of x - so agreement between the two is evidence the answer
# is right, not merely unchanged. A golden file regenerated from the code it guards asserts only
# that the code has not changed, which is a different and much weaker claim.
#
# FORMAT: blocks separated by a line of '==='. Each block is '# key=value' headers followed by one
# 'iso_date|amount_minor' row per cash flow. Amounts are paise (MNY-001), signed here because these
# are flows and not stored lots: negative is money leaving the user. Dates are ISO yyyy-MM-dd
# (TIM-002). expect_bps is the annualised rate in integer basis points (MNY-002), 1000 = 10%.
#
# Flows are listed in date order for readability only. The engine sorts and coalesces them itself,
# and InvestmentEnginePropertyTest proves the answer does not depend on the order they arrive in.

===
# case=simple-year
# expect_bps=1000
# span_days=365
# note= A full year at exactly ten percent. Hand-checkable without any tooling: one
#       rupee out, 1.10 back, 365 days apart.
2026-01-01|-10000000
2027-01-01|11000000
===
# case=loss-year
# expect_bps=-1000
# span_days=365
# note= The same year ending ten percent down. A loss has one sign change like any
#       other case and needs no special handling - but it is the case a wrong sign
#       convention would still pass, so it is pinned.
2026-01-01|-10000000
2027-01-01|9000000
===
# case=break-even
# expect_bps=0
# span_days=365
# note= Out and back with nothing gained. The root is exactly x = 1, the one value the
#       bisection can land on at its first midpoint.
2026-01-01|-10000000
2027-01-01|10000000
