Golden file for :domain:engines:goals (issue 7.1; AI-GOAL, RULE-HORIZON v1.0).

Every record is one goal. Amounts are PAISE (MNY-001), never rupees — a fixture written in rupees is
a fixture that silently passes at a hundredth of the amount it claims. Dates are ISO `yyyy-MM-dd`
(TIM-002).

Every record shares one `today`, 2026-08-30, so the whole file is reproducible to the byte (P-08) —
this engine reads no clock (TIM-001).

The status, the horizon and the ETA are asserted as well as the required monthly, because a required
monthly that came out right from the wrong branch is exactly what a golden file exists to catch: the
same figure can be produced by a normal goal, a past-due one, and one whose target is zero, and only
the verdict beside it tells them apart.

Record format — one `# key=value` per line, records separated by a line of `===`:

  target            paise, what the goal needs in total
  saved             paise, set aside so far (optional, default 0)
  planned           paise, the user's monthly plan (optional, default 0)
  target_date       ISO date the money is needed
  expect_required   paise, the largest monthly instalment
  expect_months     whole months of contribution left before the date
  expect_status     OVER_FUNDED | ON_TRACK | NO_TARGET | BEHIND | PAST_DUE
  expect_horizon    SHORT | HYBRID | LONG   (RULE-HORIZON)
  expect_eta        ISO date the plan reaches the target, or `none`

# expect_status=BEHIND
# expect_horizon=SHORT
# expect_eta=2028-11-30
