## What is **not** delivered — read this before closing the issue

**AC-1 ("prices come through our backend proxy") cannot be demonstrated.** The §22 Market Data API is
specified and unbuilt, and no issue in the backlog builds it. Phase 4 is therefore marked `[~]`, not
`[x]`.

What was built instead, and what it is worth:

- The client is **structurally incapable** of talking to anything but a pinned proxy, and is
  **provably inert** today: `NetworkConfig.UNCONFIGURED` has a blank base URL, so `MarketDataFactory`
  constructs no `OkHttpClient` at all — no pool, no DNS, no socket. One `@Provides` in
  `NetworkModule` turns it on when a proxy exists.
- A configured host **cannot be expressed without certificate pins** (§22.1). No placeholder pin was
  shipped: one that matches nothing would read as a control while protecting nothing.
- **TLS and pinning are the only untested part** of `:core:network`. MockWebServer serves cleartext
  and `NetworkConfig` refuses a cleartext host, so the suite drives the production converter, mapper
  and client construction through an `internal` seam below the handshake. Trusting a test certificate
  would need an `SSLSocketFactory` seam in the one file whose job is to prove there are none.
- Everything **either side** of the request is fully tested and two gates were broken on purpose to
  prove it: 16 tests against MockWebServer, 13 against in-memory Room with the real engine, 5 on the
  worker.

**The user-visible half of this issue is complete and shipped**: a hand-entered price now carries its
age ("as of 12 Jul · 41 days old"), which is real value with no backend, and it is what the holdings
screen shows today.

**Follow-up needed before AC-1 can be closed:** an issue that builds the §22 proxy. It does not exist
in the backlog and should be filed.
