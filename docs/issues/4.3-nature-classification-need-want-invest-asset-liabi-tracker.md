## Notes for whoever picks this up next

- **The golden file fixes the cited rule, not just the nature, and that is not decoration.** Four of
  §8.3.1's six steps can produce NEED. It is the only thing that would catch a reordered decision
  order, and it already caught one real bug.
- **`transactions.nature` holds only corrections.** Anything that writes a derived nature into it
  breaks step 4, which learns from the distinction between "the engine decided" and "the user did".
- **Do not add a nature filter or bulk re-nature to the list** without revisiting ADR-0016's storage
  decision: classifying a whole page per scroll is the case the derive-on-read choice deferred.
- **`trueSpend` is short by the interest on any EMI**, asserted as written in `NatureBreakdownTest` so
  the day `loan_amortization_rows` lands, that test fails and points at the reason.
- **Issue 4.4 is budgets**, which will want the same monthly window `observeNatureBreakdown` uses —
  it resolves the calendar month from the injected `Clock`, and a second answer computed elsewhere
  could disagree with it (TIM-001).
