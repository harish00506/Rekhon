## Acceptance criteria

- [x] **The Glance widget renders Safe-to-Spend/net worth from cached values and respects the
      privacy blur (5.3).** Both figures come from Glance's own preference state, written only by
      `:app`. On the emulator the widget showed `₹18,675.00` / `₹3,59,925.00` — byte-identical to the
      dashboard beside it — and masked to `₹•••••••` within a second of the toggle. The mask is
      `MoneyFormatter.mask`, which issue 5.5 moved down from `:core:designsystem` so the app and the
      widget cannot drift to two widths (ADR-0022).
- [x] **Carried from 5.3 (2026-08-16) — closed here.** `WidgetBlurWatcher` writes the flag with no
      database touched, so the widget hides even on a locked device. `:core:designsystem`'s `maskOf`
      was neither widened nor mirrored: the definition moved to `:core:model`, and `maskOf` delegates.
- [x] **It updates via WorkManager and works with the backend absent (P-04).** `WidgetRefreshWorker`,
      6-hourly `KEEP` plus a one-shot on each launch, no `Constraints`. Every device observation and
      the whole instrumented suite ran in airplane mode.
- [x] **Screenshot test light/dark.** Satisfied differently, and the difference is recorded rather
      than papered over — see phase 7 and ADR-0024. Light and dark were both observed on the device.
- [x] **Golden rules respected; money/time rules hold.** Paise as `Long` end to end
      (`longPreferencesKey` → `Money` → `MoneyFormatter`); nothing derived from the wall clock, which
      is what makes the refresh idempotent by construction; `null` renders as a label, never ₹0.00.
- [x] **Skill Rules satisfied** — `glance-widget` (cached output, blur-aware, WorkManager, offline),
      `workmanager-jobs` (idempotent, injected lock, no network constraint), `test-driven-development`
      (seeded regressions proved red first), `/ponytail` (no Hilt in `:widget`, no new proto, no new
      table, no second screenshot framework).

## Carried forward

1. **The widget-picker preview is the app icon, not a picture of the widget.** No `previewImage` or
   `previewLayout` is declared, so the launcher falls back to the launcher icon. Cosmetic, and the
   description line beneath it reads correctly. A static preview drawable would be a second thing to
   keep in step with the layout; a `previewLayout` is the better fix and is a small job on its own.
2. **`CfoHardcodedUiString` only sees literals passed directly to `Text(...)`.** A string threaded
   through a helper composable — `Figure(label = "Net worth")` — is not flagged, in `:widget` or in
   any `:feature:*` module. Pre-existing and not introduced here, but this issue is where it was
   proved, so it belongs on the record.
3. **The refresh cannot run while the app is locked**, by design (SEC-002). On a device that stays
   locked past six hours the widget's figures go stale with nothing on screen saying so. A staleness
   label was considered and rejected in ADR-0024 (it needs the profile zone on the render path and
   would break idempotency); if it is ever wanted, the honest form is a marker written by the
   watcher, which has no database dependency.
