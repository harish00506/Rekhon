## Acceptance Criteria

- [x] Erase destroys the DB key in the Keystore and wipes DB/caches; the data is cryptographically unrecoverable (SEC-003). **All three** Keystore chains are destroyed — database, PIN and receipts — and the deletion is *verified*, because `deleteEntry` can return without removing the key. **Narrowed on "backups", deliberately and on the record (ADR-0060 §5):** no backup exists inside app storage to wipe — issue 8.1 hands the sealed bytes straight to the file picker's URI — and a backup the user exported is sealed with *their* Argon2id passphrase, which this app never held. The screen tells the user so and asks them to delete those files themselves, rather than claiming a reach the app does not have.
- [x] It requires explicit confirmation + auth; an audit event is recorded (no PII). A word typed in the user's **own language**, then the PIN — absent on a device that has none (SEC-002 makes the lock optional), and *required* when the credential cannot be read. `AuditEvent.DATA_ERASED`, written last, with no method and no detail.
- [x] An instrumented test verifies no readable data remains. `EraseDeviceTest` writes a canary into a real encrypted database, a real Keystore-backed receipt and the settings file, erases, then reads **every byte** the app still owns looking for it — proven non-vacuous on the emulator by dropping one file from its module's inventory.
- [x] Golden rules (P-01...P-08) respected; money/time rules hold wherever amounts or dates are touched. No amount or date is computed here. P-07 holds — the app recommends and the user decides, and this is the user deciding. **P-01 drove two fixes the device run found:** the widget's plaintext cached figures, and nine workers that would have started collecting again after the erase.
- [x] All Skill Rules and label-specific rules below are satisfied. No hand-rolled crypto: the platform Keystore deletes the keys and Tink is untouched. Nothing leaves the device.
- [x] Definition of Done met (`00-issue-workflow.md` steps 9-11; `/pre-merge`).

## Guiding Principles (CLAUDE.md §1 / design spec §2)

- **P-03 Numbers from math, words from AI** - engines compute every figure; the LLM only verbalises.
- **P-01 Privacy first** - no financial data leaves the device without explicit, revocable, per-feature consent.
- **P-02 Show the work** - every output shows its inputs + the rule/model that fired + a plain-language reason.
- **P-08 Deterministic & testable** - fixed input → fixed output; randomness only via an injected, seedable source.
- **SEC-003 / P-01** - Tink/Keystore only (no hand-rolled crypto); every off-device path is consent-gated.
