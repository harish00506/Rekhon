## Acceptance Criteria

- [x] The Glance widget renders Safe-to-Spend/net worth from cached values and respects the privacy blur (5.3).
      **Carried here from 5.3 (2026-08-16) - closed.** Neither option in the note below was taken:
      rather than widening `maskOf` or mirroring it, the definition **moved down** to
      `MoneyFormatter.mask` in `:core:model`, and `:core:designsystem`'s `maskOf` now delegates. That
      keeps one definition of the fixed width without making `:widget` depend on a Material3 module
      for three lines of text formatting. See
      [ADR-0024](../adr/0024-the-widget-renders-from-glance-state-not-the-database.md).
      **The original note from 5.3:** That issue built the blur and could not honour it in
      the widget because `:widget` is still a `ModulePlaceholder`, so it left the criterion unticked
      rather than claiming it. What to reuse: read `SettingsStore.observe().privacyBlurEnabled` — the
      same flag the app reads — and render `maskOf(amount)` from
      `:core:designsystem`'s `PrivacyBlur.kt`, which is `internal`, so either widen it or mirror the
      fixed-width mask. **Fixed width matters**: a mask sized to the digits leaks the order of
      magnitude, which on a home screen is the whole exposure. See
      [ADR-0022](../adr/0022-privacy-blur-masks-text-and-sets-flag-secure.md).
- [x] It updates via WorkManager and works with the backend absent (P-04). `WidgetRefreshWorker`,
      6-hourly `KEEP` plus one `refreshNow` per launch, no `Constraints`; every check below was run
      in airplane mode.
- [x] Screenshot test light/dark - **satisfied differently, and the difference is on the record.**
      Paparazzi cannot render Glance (it emits `RemoteViews` for an `AppWidgetHost`). Covered by
      `runGlanceAppWidgetUnitTest` on the JVM and `WidgetDeviceTest` inflating real RemoteViews on
      a device; light and dark were observed on the emulator and logged. See ADR-0024.
- [x] Golden rules (P-01...P-08) respected; money/time rules hold wherever amounts or dates are touched.
- [x] All Skill Rules and label-specific rules below are satisfied.
- [x] Definition of Done met (`00-issue-workflow.md` steps 9-11). Merged to `dev`; the push is a
      documented SKIP because this repo has no remote, as at 5.4.

## Guiding Principles (CLAUDE.md §1 / design spec §2)

- **P-03 Numbers from math, words from AI** - engines compute every figure; the LLM only verbalises.
- **P-01 Privacy first** - no financial data leaves the device without explicit, revocable, per-feature consent.
- **P-02 Show the work** - every output shows its inputs + the rule/model that fired + a plain-language reason.
- **P-08 Deterministic & testable** - fixed input → fixed output; randomness only via an injected, seedable source.
- **§21.6 theming/i18n** - strings in `strings.xml` (ICU plurals); colours/dimensions from theme tokens.
