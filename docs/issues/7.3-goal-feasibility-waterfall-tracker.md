- [x] **Feasibility flags under-funded goals deterministically** — against the observed P50 rather
      than the forecast (9.2 absent; ADR-0035). `Feasibility.UNKNOWN` where the surplus cannot be
      resolved, never a false verdict.

      shown** (P-02) — `min(remaining, required)` in a fold, in `goal.sort_order`, with the plan card
