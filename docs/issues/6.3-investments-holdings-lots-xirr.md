## Acceptance Criteria

- [x] Holdings/lots are stored; XIRR is computed deterministically over dated flows (converges, tested vs known cases).
      `investment_holding` + `investment_lot` at schema 18; `Xirr.solve` bisects a fixed bracket 128 times
      with no early exit (ADR-0028). Eight golden cases match an **independent** 60-digit implementation.
- [x] Values are `Money` paise; provenance is attached to results.
      **Deviation:** the engine reads no `Clock` **at all** and takes no `asOf` — a holding's terminal
      cash flow is dated by `priced_on_iso_date`, so the answer cannot change because the day did (P-08).
      The clock is read in `RoomInvestmentRepository` for row stamps and provenance only (TIM-001).
- [x] Golden-file + property tests (empty, single-flow, loss cases).
      Empty and single-flow are `TOO_FEW_FLOWS`; the loss cases are golden blocks `loss-year` (−1000 bps)
      and `break-even` (0 bps), plus `NOT_BRACKETED` for a loss beyond the engine's floor.
      Seven properties over 500 seeded cases each.
- [x] Golden rules (P-01...P-08) respected; money/time rules hold wherever amounts or dates are touched.
- [x] All Skill Rules and label-specific rules below are satisfied.
- [x] Definition of Done met (`00-issue-workflow.md` steps 9-11; `/pre-merge`).
      Step 9's emulator gate ran on 2026-08-25 (AVD `CfoTest`, API 34): the migration round-trip,
      the app smoke suite, a holding created by hand showing **10.0% a year**, airplane mode and the
      privacy blur. Only step 10-11's commit/PR remains, which needs the user's go-ahead (§7).

## Guiding Principles (CLAUDE.md §1 / design spec §2)

- **P-03 Numbers from math, words from AI** - engines compute every figure; the LLM only verbalises.
- **P-01 Privacy first** - no financial data leaves the device without explicit, revocable, per-feature consent.
- **P-02 Show the work** - every output shows its inputs + the rule/model that fired + a plain-language reason.
- **P-08 Deterministic & testable** - fixed input → fixed output; randomness only via an injected, seedable source.
- **AI-ARC-003/006** - every engine result carries provenance (engineId/version/inputWindow/computedAt/confidence/evidence).
