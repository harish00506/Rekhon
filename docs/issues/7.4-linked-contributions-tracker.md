## Notes for the reviewer

- **Three gates were proved red**, and the third exposed a fourth problem: the golden split assertion
  was a **tautology** on the first attempt, because it derived the expectation with the same
  subtraction the engine performs. It now reads `expect_declared` from the file.
- **Two defects were found by running the app**, neither of which any test would have caught: a
  sentinel date rendered at the user, and a helper string that stopped being true the moment this
  shipped.
- **One defect was found by reasoning about the change**, and it is the most dangerous: the editor
  loaded `goal.saved`, which this issue redefined as the *total*. Left alone it would have folded the
  evidenced half into the hand-typed one on every edit. Verified fixed on the device.
- **The migration was proved on a real SQLite**, not only against the exported schema.
  `runMigrationsAndValidate` does **not** compare index names (7.1's finding), so
  `migrate21To22_...` asserts all eight against `sqlite_master` itself, and checks that the
  unique index actually refuses a second link of the same pair — which is what makes the
  repository's revive-rather-than-mint logic correct rather than merely intended.
