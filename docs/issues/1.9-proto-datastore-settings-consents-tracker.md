## Decisions worth recording

- **Real protobuf, no fallback needed.** The plugin and `protoc` work with AGP 8.11, so §21.3's
  "Proto DataStore" is met literally and no ADR was required.
- **`OkioStorage` instead of the default file storage.** Not a preference: the default cannot
  replace an existing file on Windows, which made this module's tests unrunnable locally. An
  untestable consent ledger is unacceptable for the one component P-01 rests on, and using the same
  storage engine in tests and production beats special-casing tests.
- **The most valuable outcome of this issue is a test-quality fix.** The stores return
  `Result<Unit, AppError>` rather than throwing (§21.6) — which means a test that ignores the
  return value cannot fail. Six tests were green over writes that were erroring. `assertWritten()`
  now fails the test at the write, and the same trap applies to every `Result`-returning API in
  this codebase.
- **Consents are a map keyed by a stable feature id**, so adding one in issue 3.9 is not a schema
  migration. The id is persisted: renaming one orphans a user's decision, so entries are deprecated,
  never renamed — the same rule `ai/` uses for its rule ids.
- **Absence is never consent.** A missing record, an unknown id and an empty store all read as not
  granted, expressed once in `ConsentState.NOT_GRANTED`.
- **No corruption handler.** The obvious `ReplaceFileCorruptionHandler { defaultValue }` would
  silently discard every consent decision the user made. Corruption is `Err(Storage)` instead.
- **The `Clock` seam from issue 1.3 is now satisfiable but not yet wired.** `SettingsSnapshot`
  carries `profileTimeZoneId`; connecting it to `SystemClock`'s zone provider needs the DI graph
  (issue 1.10). Flagged rather than half-wired.
