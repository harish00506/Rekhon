## Description

A one-tap privacy blur that hides all amounts on screen (and in the widget/screenshots) for shoulder-surfing and screen-sharing safety.

## Acceptance Criteria

- [x] The toggle blurs every monetary value app-wide; state persists in DataStore — **both**
      rendering paths converted (`CfoAmountText` and the `stringResource` placeholders a component
      alone cannot reach), persisted in `privacy_blur_enabled`, proven to survive a force-stop.
- [x] Combined with FLAG_SECURE (11.2) so amounts are not captured — `screencap` returns **0 bytes**
      while blurred. **The widget half was NOT met here** — `:widget` was still a `ModulePlaceholder`
      — and was carried to issue 5.5. **Closed there on 2026-08-17:** the blur now reaches the
      launcher, written by `WidgetBlurWatcher`, which touches no database so the widget hides even on
      a locked device. The mask stayed one definition rather than two: `maskOf` moved down to
      `MoneyFormatter.mask` in `:core:model`, and this module's `maskOf` delegates to it
      ([ADR-0024](../adr/0024-the-widget-renders-from-glance-state-not-the-database.md)).
- [x] A Compose UI test asserts amounts are hidden; an accessible label is present —
      `DashboardPrivacyBlurTest` sweeps every rendered string; masked amounts announce "Amount
      hidden" rather than the figure.
- [x] Golden rules (P-01...P-08) respected; money/time rules hold wherever amounts or dates are touched.
- [x] All Skill Rules and label-specific rules below are satisfied.
- [x] Definition of Done met (`00-issue-workflow.md` steps 9-11) — step 10's merge is the one step left.

**Exempt by design:** editable amount fields (add-transaction, account editor, budget editor, the
transaction filter's bounds). Masking what someone is typing replaces their input with dots and
leaves them unable to correct it, and a filter bound is a number the user supplied rather than a fact
about their money.

The choice to mask text rather than blur pixels, and to set `FLAG_SECURE` here rather than wait for
11.2, is recorded in **[ADR-0022](../adr/0022-privacy-blur-masks-text-and-sets-flag-secure.md)**.

## Guiding Principles (CLAUDE.md §1 / design spec §2)

- **P-03 Numbers from math, words from AI** - engines compute every figure; the LLM only verbalises.
- **P-01 Privacy first** - no financial data leaves the device without explicit, revocable, per-feature consent.
- **P-02 Show the work** - every output shows its inputs + the rule/model that fired + a plain-language reason.
- **P-08 Deterministic & testable** - fixed input → fixed output; randomness only via an injected, seedable source.
- **SEC-003 / P-01** - Tink/Keystore only (no hand-rolled crypto); every off-device path is consent-gated.
- **§21.6 theming/i18n** - strings in `strings.xml` (ICU plurals); colours/dimensions from theme tokens.
