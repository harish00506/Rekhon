## Verified vs unverified — the honest ledger

**Verified:** everything in the log above, on this machine and on one emulator.

**Not verified, and why:**

- **The chosen time zone reaching `Clock` end to end.** The zone is proved to persist (device, above)
  and `ProfileZoneProvider` is proved to read the setting and to fall back correctly (7 JVM tests
  from issue 1.10, including the case that distinguishes "fell back" from "the collector died").
  What cannot be observed yet is the *result*: no screen renders a date, so there is nothing on
  screen that would change if the zone were ignored. This becomes checkable with issue 5.1.
- **CI has still never run.** The repository has no git remote, so every green here is a local green
  on one Windows machine — unchanged from the Epic 1 handoff, and still the project's largest
  untested surface.
- **One device, one API level.** `CfoTest` (AVD), API 34, software rendering. No physical device, no
  other API level, no tablet or landscape.

**Cosmetic, deliberately not fixed:** inside `CfoCard` a title and its body sit tight against each
other at 200% font — legible, not clipped, but cramped. The right fix is spacing inside `CfoCard`,
which is design-system territory (issue 1.8), not this issue's.
