      Fifteen defaults are seeded on a real profile — before this issue only `DemoDataset` ever wrote
      a category row — and each is renameable, re-natureable, nestable one level and deletable.

      `CLS-CAT-001`…`015` and `CLS-MER-001`…`013` in `ai/knowledge/classification-kb.json` v1.1.

      30 repository cases, 20 ViewModel cases, 13 Compose cases, 6 model cases, 5 drift cases.

      a row no protection. **P-02:** the delete dialog states its count, and says so honestly when it
      cannot read one. **P-04:** no network on the path at all. **P-08:** the seed is idempotent and
      its ids derived. **MNY-001/TIM-001:** no amounts here; the only clock read is the row stamp,
      from the injected `Clock`.
- [x] All Skill Rules and label-specific rules below are satisfied.
- [x] Definition of Done met — with two documented `SKIP`s (instrumented E2E, and the commit itself,

## Guiding Principles (CLAUDE.md §1 / design spec §2)

- **P-03 Numbers from math, words from AI** - engines compute every figure; the LLM only verbalises.
- **P-01 Privacy first** - no financial data leaves the device without explicit, revocable, per-feature consent.
- **P-02 Show the work** - every output shows its inputs + the rule/model that fired + a plain-language reason.
- **P-08 Deterministic & testable** - fixed input → fixed output; randomness only via an injected, seedable source.

## Workflow Rules — While Solving

### Universal (apply to every issue)

1. Define expected vs actual behaviour with evidence (logs, tests).
2. Reproduce before fixing; binary-search to isolate the root cause.
3. Form testable hypotheses; switch to formal debugging after 10 min of guessing.
4. Smallest correct diff; match the surrounding code style.
5. Verify the fix with the original reproduction case.
6. **Respect the boundaries** - `feature → domain → data/core` (ARC-001); engines pure-Kotlin (ARC-002); repositories are the only DAO touchers (ARC-005).

### Issue-specific (from the SRS)

1. Thresholds/rules are data rows, never hardcoded (CLAUDE §6, AI-ARC-006).

### Label-specific

1. Merchant/category rules are versioned data rows cited by ID, not code (§29/AI-ARC-006).

### Epic-specific

1. Categorisation and budget thresholds are versioned data rows cited by ID - never hardcoded (§29).
