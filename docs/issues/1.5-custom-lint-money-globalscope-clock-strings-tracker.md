## Decisions worth recording

Full reasoning in **[ADR-0001](../adr/0001-custom-lint-module-and-money-heuristic.md)** — the
repository's first ADR, which also partly closes audit G-12.

- **Five detectors, not the four in the task.** `CLAUDE.md` §5 already promised the PII-logging
  rule would land here; shipping four would have left the rulebook asserting a gate that does not
  exist — the exact defect this issue exists to remove.
- **Money is detected by name + type, never type alone.** If the type could tell us, `Money` would
  not need to exist. Whole-word camelCase matching, so `expand` never matches `pan`.
- **Module scoping checks path *or* package.** Path alone was implemented first and looked correct
  — it passed nothing, silently, because the test harness relocates fixtures. A rule that stops
  firing when a directory moves still *reads* as enforced, which is the worst failure mode here.
- **`:core:common` is exempt from TIM-001**: `SystemClock` is the sanctioned wall-clock read, and a
  rule that bans its own implementation gets suppressed.
- **No coverage bound on `:lint`.** A line-coverage number would measure the wrong thing; these
  detectors are proved by the fixture pairs plus a seeded violation failing a real build. `:lint`
  does get ktlint and detekt — §21.6 applies to every module, enforcement layer included.
- **`lintVersion` must track `agp`** (lint = AGP + 23), or the detectors compile against a
  different API than the one running them.
