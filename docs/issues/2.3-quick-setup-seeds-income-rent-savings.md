## Acceptance Criteria

- [x] The user can seed income/rent/savings; values create the matching accounts/recurring records deterministically.
      Delivered as a `profile` row, three nature-level `budget` envelopes and up to three
      `recurring_rule` rows, written in one transaction at schema v3. Ids are **derived**
      (`<profile>:budget:<nature>:<period>`), never generated, so re-running onboarding updates the
      same rows instead of duplicating them. **No account row** — issue 2.5 owns accounts, so
      `recurring_rule.account_id` is left null for it to attach ([ADR-0004](0004-quick-setup-persists-budgets-and-recurring-rules.md)
      records this and what every later issue is expected to add).
- [x] It is skippable; nothing is fabricated if skipped. Enforced independently at three layers: an
      unanswered field produces no engine output, Skip never calls the repository, and an empty plan
      writes no row at all — not even the profile.
- [x] Amounts are stored as `Money` paise and covered by tests. `:core:model` holds at **100%**
      coverage; the stored columns are asserted as INTEGER paise against real SQLite, and the
      envelopes are proven to total the income exactly across 800 seeded amounts.
- [x] Golden rules (P-01...P-08) respected; money/time rules hold wherever amounts or dates are touched.
      No network on any path (P-04); every figure from the engine, none from the UI (P-03); the
      summary shows the rule ids behind each number (P-02); the plan is deterministic with the clock
      injected (P-08, TIM-001); the budget month resolves in the profile zone (TIM-002).
- [x] All Skill Rules and label-specific rules below are satisfied. **One deliberate exception:**
      CLAUDE.md §6 (thresholds as `ai/` data rows) is deferred — see
      [ADR-0005](0005-quick-setup-thresholds-deferred-rulebook-loader.md), guarded by a drift test
      that was proven to fail before being trusted.
- [ ] Definition of Done met (`00-issue-workflow.md` steps 9-11; `/pre-merge`). **Blocked on step 9's
      real gate:** there is no device or emulator on this machine (`adb: command not found`), so the
      app has never been launched and the 2→3 migration round-trip has never executed. Everything
      else is green — 536 tests, 0 skipped.

## Guiding Principles (CLAUDE.md §1 / design spec §2)

- **P-03 Numbers from math, words from AI** - engines compute every figure; the LLM only verbalises.
- **P-01 Privacy first** - no financial data leaves the device without explicit, revocable, per-feature consent.
- **P-02 Show the work** - every output shows its inputs + the rule/model that fired + a plain-language reason.
- **P-08 Deterministic & testable** - fixed input → fixed output; randomness only via an injected, seedable source.
- **§21.6 theming/i18n** - strings in `strings.xml` (ICU plurals); colours/dimensions from theme tokens.
