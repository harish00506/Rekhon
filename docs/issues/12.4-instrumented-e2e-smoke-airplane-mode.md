## Acceptance Criteria

- [x] The E2E test runs the full core flow on an emulator including an airplane-mode leg (P-04). `OfflineEndToEndTest` turns the radio **genuinely off** via `executeShellCommand` (which runs as shell — the app is never granted `WRITE_SECURE_SETTINGS`), drives launch → demo seed → dashboard figures → transactions, and **restores the radio in `@After` even on failure**. Until this issue **nothing in the repository had ever turned airplane mode on**: P-04 lived in three source comments and in trackers where a human toggled a setting and remembered to.
- [x] The export/import round-trip is asserted; failure blocks release. `ArchiveRoundTripDeviceTest` runs it on **real SQLCipher**: seed → export → delete the database *and its wrapped key* → reopen clean → import → every row back, amounts exact to the paise. Deleting the key matters — re-opening generates a new one, so the import cannot be passing on data the old database retained. A second test asserts the failure that matters more: **an incompatible archive is refused and changes nothing**, because a wipe-then-fail would lose everything the user had.
- [x] It runs via `connectedDebugAndroidTest` in CI where a device is available. `offlineSmoke` puts **`:app:connectedDebugAndroidTest` in CI for the first time** — the Definition of Done named it and no job ran it. `restoreDrill` stays named separately because DRL-001 makes the backup drill a release gate in its own right.
- [x] Golden rules respected. **P-04 is the whole point**, and MNY-001 is served deliberately: the round-trip fixture is ₹1,23,456.79 rather than a round number, so a paise-vs-rupee slip or a floating-point round trip lands somewhere visibly wrong instead of back on the same tidy figure.
- [x] All Skill Rules and label-specific rules below are satisfied.
- [x] Definition of Done met (`00-issue-workflow.md` steps 9-11; `/pre-merge`).

**What a mutation found, and what it cost.** Stripping the toggle *and* the assertions left the UI flow **passing with the radio on** — the demo path never touches the network, so "the flow worked" proves nothing about offline by itself. The gate's strength is the toggle plus the two `isAirplaneModeOn()` assertions, verified by making the toggle a no-op and watching the test fail.

**A check was built, measured and deleted.** To strengthen it further the test also asserted an outbound socket genuinely failed. Measuring killed it: with airplane mode **off**, the CI emulator still reports `Network is unreachable` (the host reaches 8.8.8.8 fine), so that check **can never fail** there. It was removed rather than kept — a check that always passes is worse than none, because it looks stronger. Recorded in ADR-0067 so the next person to try it finds out.

## Guiding Principles (CLAUDE.md §1 / design spec §2)

- **P-03 Numbers from math, words from AI** - engines compute every figure; the LLM only verbalises.
- **P-01 Privacy first** - no financial data leaves the device without explicit, revocable, per-feature consent.
- **P-02 Show the work** - every output shows its inputs + the rule/model that fired + a plain-language reason.
- **P-08 Deterministic & testable** - fixed input → fixed output; randomness only via an injected, seedable source.
