## Acceptance Criteria

- [x] Signals are derived from proxy data (6.5) + the versioned KB; deterministic with provenance; degrade to cached + staleness offline (P-04). — the closes issue 6.5 already fetches are appended to `market_close` (schema 29) and the engine reads **only** that cache, so the screen scores with the network off and says how old its newest price is; every result carries `EngineProvenance` citing `MKT-SIGNALS v1.1`.
- [x] The Opportunity screen shows each signal's inputs + rule (P-02); advisory only (P-07). — each signal shows the number it measured beside its points, the ones with no feed say *"not measured, so it counts for nothing either way"* rather than scoring zero, the verdict carries its own walk-forward hit rate (or the honest absence of one), a blocked suggestion names the gate that blocked it, and the last line is *"This screen never buys anything."*
- [x] Golden-file test. — eight histories through an independent Python oracle (`src/test/resources/golden/market_oracle.py`), compared row by row.
- [x] Golden rules (P-01...P-08) respected; money/time rules hold wherever amounts or dates are touched. — nothing leaves the device to build the history (P-01); the engine computes every figure and the screen only renders it (P-03); closes are `Long` paise and every rate an integer bps (MNY-001/002); dates are ISO `LocalDate` strings and today comes from the injected `Clock` (TIM-001/002); 300 seeded markets prove fixed input → fixed output (P-08).
- [x] All Skill Rules and label-specific rules below are satisfied. — one public interface + result types, `internal` implementation, `MarketSignalEngineFactory.create()`, Hilt-injected (ARC-003); the module is pure Kotlin (ARC-002).

## Guiding Principles (CLAUDE.md §1 / design spec §2)

- **P-03 Numbers from math, words from AI** - engines compute every figure; the LLM only verbalises.
- **P-01 Privacy first** - no financial data leaves the device without explicit, revocable, per-feature consent.
- **P-02 Show the work** - every output shows its inputs + the rule/model that fired + a plain-language reason.
- **P-08 Deterministic & testable** - fixed input → fixed output; randomness only via an injected, seedable source.
- **AI-ARC-003/006** - every engine result carries provenance (engineId/version/inputWindow/computedAt/confidence/evidence).
- **P-07 Advice, never orders** - the app recommends and simulates; the user decides. No auto-executed money movement.
