# Issue 7.1 — Goals engine (AI-GOAL) Tracker

**Parent issue:** [7.1-goals-engine-ai-goal.md](7.1-goals-engine-ai-goal.md)  
**Strategy:** Ship the engine **and the way into it** — a `goal` table, a repository and a screen —
rather than an engine alone. The written acceptance criteria are engine-only, but an engine nobody
can put a goal into cannot be exercised, and that is precisely the bug issue 6.7 found in 6.5. Then
pay [ADR-0021](../adr/0021-safe-to-spend-buffer-and-goal-stand-in.md)'s debt: replace the
INVEST-envelope stand-in in Safe-to-Spend with the real figure.

  `runMigrationsAndValidate`. It does not. Corrected, and a real assertion added.

  without 6.7's `.gitignore`) had swept two PKCS#12 keystores into a commit, which was reset and the
  ignore rules carried across.
