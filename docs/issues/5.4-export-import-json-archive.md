## Acceptance Criteria

- [x] Export writes a versioned JSON archive locally; import restores it losslessly — the round-trip
      test seeds **every one of the fourteen tables and every nullable column**, because a round trip
      only covers what its fixture populates. Watched go red against one dropped table.
- [x] `Money` stays paise; the schema is versioned; there is no network path (P-01/P-04) —
      `ArchiveFormatTest` pins `amountMinor` as an integer, the envelope carries `archiveVersion` and
      `schemaVersion`, and an archive from another schema is refused **before anything is deleted**.
- [x] Handles empty and large datasets; covered by tests — an empty profile invents nothing, and
      2,000 transactions prove the import holds inside one transaction.
- [x] Golden rules (P-01...P-08) respected; money/time rules hold wherever amounts or dates are touched.
- [x] All Skill Rules and label-specific rules below are satisfied.
- [x] Definition of Done met (`00-issue-workflow.md` steps 9-11) — step 10's merge is the one left.

**Deliberately excluded, argued in [ADR-0023](../adr/0023-archive-replaces-and-carries-no-blobs.md):**
receipt image bytes (attachment *rows* travel; a plaintext file must never carry decrypted receipts
off the device) and `audit_log` (no `profile_id`, so the schema cannot scope it to the exported
profile). **Import replaces rather than merges**, behind an explicit confirmation.

## Guiding Principles (CLAUDE.md §1 / design spec §2)

- **P-03 Numbers from math, words from AI** - engines compute every figure; the LLM only verbalises.
- **P-01 Privacy first** - no financial data leaves the device without explicit, revocable, per-feature consent.
- **P-02 Show the work** - every output shows its inputs + the rule/model that fired + a plain-language reason.
- **P-08 Deterministic & testable** - fixed input → fixed output; randomness only via an injected, seedable source.
- **SEC-003 / P-01** - Tink/Keystore only (no hand-rolled crypto); every off-device path is consent-gated.
