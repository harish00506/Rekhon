## 3. Objective — what this task will do
Add a sealed `Result<out T, out E>` (`Ok(value)` / `Err(error)`) with `map`, `flatMap`, `mapError`,
`getOrElse`, `fold`, and a sealed `AppError` hierarchy (e.g. `Validation`, `NotFound`, `Storage`,
`Network`, `Crypto`, `Unexpected`) carrying a stable code + user-safe message (no PII). This is the
return type for every engine `compute` and repository call.

**Why now / rationale:** it is referenced by the `new-engine` skill's contract and by every
repository; defining it first keeps error handling uniform and exhaustive from task one.

## 4. Scope
**In scope**
- `Result` type + combinators; `AppError` sealed hierarchy with codes; a `runCatchingToResult`
  boundary helper that converts a thrown exception at the DB/network edge into an `Err`.

**Out of scope (`/ponytail`)**
- Don't add a third-party functional library (Arrow) — a small hand-rolled sealed type is enough
  (YAGNI). Localised error strings live at the UI edge, not here.

## 5. Dependencies

## 7. Rules to follow
- **§21.6 errors** — no exceptions across boundaries; the only place exceptions are caught is the
  DB/network edge via `runCatchingToResult`, converting to `AppError`.
- **Logging** — `AppError.message` is user-safe; **no PII/amounts** in error text (lint-stripped in release).
- **Null-hostile** — absence is `AppError.NotFound` or an `Ok` of an empty domain type, never `null`.

## 8. Implementation notes
```kotlin
sealed interface Result<out T, out E> {
    data class Ok<T>(val value: T) : Result<T, Nothing>
    data class Err<E>(val error: E) : Result<Nothing, E>
}
inline fun <T, E, R> Result<T, E>.map(f: (T) -> R): Result<R, E>
inline fun <T, E, R> Result<T, E>.flatMap(f: (T) -> Result<R, E>): Result<R, E>

sealed class AppError(val code: String, val message: String) {
    class Validation(field: String) : AppError("validation", "Invalid $field")
    object NotFound : AppError("not_found", "Not found")
    class Storage(cause: String) : AppError("storage", "Storage error")
    class Network(retryable: Boolean) : AppError("network", "Network unavailable")
    class Crypto(op: String) : AppError("crypto", "Security error")
    class Unexpected(cause: String) : AppError("unexpected", "Something went wrong")
}
```

## 9. Acceptance criteria
- [ ] **AC1** — Given `Ok(2)`, when `map { it * 3 }`, then `Ok(6)`; `Err(e).map{…}` stays `Err(e)`.
- [ ] **AC2** — Given a thrown `IOException` inside `runCatchingToResult`, then it returns `Err(AppError.Storage(...))` — nothing propagates.
- [ ] **AC3** — `when (result)` over `Ok`/`Err` is exhaustive without an `else` (sealed).
- [ ] **AC4** — No `AppError.message` contains an amount, account name, or other PII.
