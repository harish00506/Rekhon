## 3. Objective — what this task will do
Define a `Clock` interface (`nowUtcMillis(): Long`, `today(zone): LocalDate`, `zone(): ZoneId`)
with a real implementation and a `FakeClock` test double, plus a `DispatcherProvider`
(`main`/`io`/`default`) with a real impl and a test impl backed by a test dispatcher. All domain
calendar logic (day rollover, month boundaries, due dates) uses the profile time zone via this
`Clock`.

**Why now / rationale:** forecasting, budgets, reminders, and the orchestrator's day-rollover all
hinge on correct, injectable time. Without this, tests can't control "today" and TIM-001 can't hold.

## 7. Rules to follow
- **TIM-001** — no `System.currentTimeMillis()`, `Instant.now()`, `LocalDate.now()` in `:domain`/`:core:model`; go through `Clock`.
- **TIM-002** — date-only values are ISO `LocalDate` strings, never midnight epoch.
- **ARC-006** — expose dispatchers for injected structured concurrency; never `GlobalScope`.
- **P-08** — deterministic: `FakeClock` makes "now" fixed and controllable.

## 8. Implementation notes
```kotlin
interface Clock {
    fun nowUtcMillis(): Long
    fun zone(): ZoneId                 // the profile time zone
    fun today(): LocalDate             // = Instant(now).atZone(zone).toLocalDate()
}
interface DispatcherProvider { val main: CoroutineDispatcher; val io: CoroutineDispatcher; val default: CoroutineDispatcher }
```
- `FakeClock(fixedMillis, zone)` with `advanceBy(duration)` for tests.
- Prefer `java.time` (API 26+ per NFR-008) or `kotlinx-datetime` per the pinned catalog — pick one, cite it.

## 9. Acceptance criteria
- [ ] **AC1** — Given `FakeClock` at `2026-03-31T23:30Z` with zone `Asia/Kolkata`, when `today()`, then it returns `2026-04-01` (IST is +5:30).
- [ ] **AC2** — Given two epochs on the same profile day but different UTC days, when `isSameProfileDay`, then `true`.
- [ ] **AC3** — Grep of `:domain`/`:core:model` for `System.currentTimeMillis()` returns nothing (also lint-enforced by task 1.1.5).
- [ ] **AC4** — `DispatcherProvider` test impl lets a coroutine test advance virtual time deterministically.
