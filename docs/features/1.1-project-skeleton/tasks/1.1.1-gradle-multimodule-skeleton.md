## 3. Objective — what this task will do
Create `settings.gradle.kts` declaring the full module graph (§21.2), a `gradle/libs.versions.toml`
version catalog pinning §21.3, and `build-logic` convention plugins (`kotlin-jvm`, `android-library`,
`android-app`, `hilt`, `quality`) so modules stay consistent. Each module is a compiling stub with
one placeholder + its test source set. Wire the existing [`.github/workflows/ci.yml`](../../../../.github/workflows/ci.yml)
to invoke the now-real Gradle tasks.

**Why now / rationale:** every other task needs a module to live in and a green build to land against.

## 4. Scope
**In scope**
- `settings.gradle.kts`, root `build.gradle.kts`, `gradle/libs.versions.toml`, `build-logic/`.
- Compiling stub for each module in §21.2 with a `src/test` folder.
- A build check that fails if `:core:model` or any `:domain:*` applies an Android plugin (ARC-002).

**Out of scope (`/ponytail`)**
- Any real feature logic (later tasks). No SQLCipher wiring (Feature 1.2). No Compose screens (1.3+).

## 7. Rules to follow
- **ARC-001/002** — one-way deps; `:core:model` + `:domain:*` are pure Kotlin (no `com.android.*` plugin). Enforce with a Gradle check.
- **§21.3 pinned stack** — versions live only in `libs.versions.toml`; no hardcoded versions in module build files.
- **§21.6** — ktlint official + detekt applied via the `quality` convention plugin to every module.
- **JDK 17** toolchain set once in convention plugins.

## 8. Implementation notes
- **Files:** `settings.gradle.kts`, `build.gradle.kts`, `gradle/libs.versions.toml`,
  `build-logic/settings.gradle.kts`, `build-logic/convention/…` (Kotlin plugins).
- **Module graph (§21.2):** `:app`; `:core:model :core:common :core:database :core:datastore
  :core:network :core:crypto :core:designsystem`; `:domain:engines:* :domain:usecase`;
  `:data:repository`; `:ml:ocr :ml:llm`; `:feature:*`; `:sync:backup`; `:widget`.
- **ARC-002 check:** a small task in the `kotlin-jvm` convention plugin that throws if
  `com.android` plugins are present on a pure-Kotlin module.
- Keep convention plugins minimal — resist adding tooling not in §21.3.
