## 3. Objective — what this task will do
Implement custom Android `Detector`s that fail the build on: (1) a `Double`/`Float`/`BigDecimal`
used for a monetary value (name/type heuristics: `Money`-adjacent identifiers, `*_minor`, `amount`,
`price`, `balance`); (2) `GlobalScope` usage; (3) `System.currentTimeMillis()` / `Instant.now()` /
`LocalDate.now()` in `:domain`/`:core:model`; (4) hardcoded user-visible string literals in
`:feature:*` UI. Wire them into every module via the `quality` convention plugin so CI blocks on them.

**Why now / rationale:** these four rules are review-blocking in the SRS. Automating them means the
`money-time-audit` skill becomes a fast confirmation, not the last line of defence.

## 4. Scope

## 7. Rules to follow
- The detectors **encode** MNY-001, TIM-001, ARC-006 (GlobalScope), and the strings rule — get their
  scoping right (e.g. clock rule applies to `:domain`/`:core:model` only, not `:app` DI).
- Severity **error**, CI-blocking; empty baseline (do not grandfather violations in).
- Keep false positives near zero — prefer missing an exotic case over blocking valid code; document heuristics.

## 8. Implementation notes
- Module `:lint` (a `java-library` with `com.android.tools.lint:lint-api`). Register an
  `IssueRegistry`; each `Issue` maps to a `Detector`.
- **MoneyDoubleDetector** — flags `Double`/`Float`/`BigDecimal` on declarations whose name/type
  matches the money heuristic list.
- **GlobalScopeDetector** — flags references to `kotlinx.coroutines.GlobalScope`.
- **DomainClockDetector** — flags banned time calls when the containing module path matches
  `:domain`/`:core:model`.
- **HardcodedUiStringDetector** — flags string literals passed to `Text(...)`/content descriptions in `:feature:*`.
- Test with `LintDetectorTest`: each detector has a fixture that **should** warn and one that **should not**.

## 9. Acceptance criteria
- [ ] **AC1** — A `val amountMinor: Double` in any module → lint **error**; changing it to `Money`/`Long` → clean.
- [ ] **AC2** — `GlobalScope.launch{…}` anywhere → lint **error**.
- [ ] **AC3** — `System.currentTimeMillis()` in a `:domain:*` file → lint **error**; the same call in `:app` DI → allowed.
- [ ] **AC4** — `Text("Hello")` in a `:feature:*` composable → lint **error**; `Text(stringResource(R.string.hello))` → clean.
- [ ] **AC5** — `./gradlew lint` is CI-blocking; the baseline is empty.

## 12. Risks & edge cases
- **False positives** (e.g. a `Double` animation fraction named `balance`) → tighten heuristics, add a negative fixture; err toward not blocking valid code.
- Lint-API version drift → pin via the catalog; `source-driven-development` for the current API.
- Path-based module scoping brittle → test T4/T5 both directions.
